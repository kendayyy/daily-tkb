# Daily TKB

Thời khóa biểu tuần dạng lưới (Next.js 14 + Tailwind + Zustand + localStorage).

Spec: [`spec/specs.md`](spec/specs.md). Plan: [`plans/tkb-grid.md`](plans/tkb-grid.md).

`spec/` và `plans/` không import vào app.

## Chạy

```bash
npm install
npm run dev
```

Mở http://localhost:3000

```bash
npm run build
```

Xuất tĩnh vào `out/` (GitHub Pages / static host). Vercel: framework Next.js.
